# Stability Analysis of IEEE 30 Bus System with HVDC Integration

A power systems engineering study analyzing transient steady-state responses, line loading thresholds, and voltage profiles when integrating High-Voltage Direct Current (HVDC) links into a standardized IEEE 30 Bus transmission network grid.

## Project Objectives & Scope
- Design an integrated AC-DC system modeling proper transmission constraints.
- Execute **Load Flow Analysis** to map active and reactive power routing across all system buses.
- Conduct comparative evaluations of system profiles between conventional High-Voltage AC (HVAC) networks and modern bipolar HVDC lines.
- Analyze line loading limit thresholds and check bus voltage stability under high load stresses.

## References
- A. Al-Taee and A. A. R. Altahir, "An Optimal Power Flow for HVDC and Comparisons with High-Voltage AC Grid for IEEE-30 Bus," *ICEMG*.
- Standard IEEE 30 Bus Grid data matrices.
